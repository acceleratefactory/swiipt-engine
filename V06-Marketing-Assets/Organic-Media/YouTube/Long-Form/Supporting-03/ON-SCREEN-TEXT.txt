ON-SCREEN TEXT (deterministic; short lines only)

[The constraint that kills most rosters]
  Ask most couples why the night split never sticks and you get the same answer: he works tomorrow.
  It is a real constraint.
[Why 'he works, so he sleeps' is not a system]
  If the working parent always sleeps because they work tomorrow, then the other parent owns every night, permanently.
  That is not a compromise; it is a default that nobody wrote down.
[Planning the work night instead of avoiding it]
  The shift is to plan the work night rather than exempt it.
  A working parent cannot usually own 1 AM to 5 AM on a work night.
[The early block and the late block]
  So you name which block each adult realistically owns on a work night, and you write the clock times around the real shift.
  If the working parent leaves at seven, the late block belongs to them: they take the baby so the other parent gets a stretch before the hardest hours.
[Weekends and recovery]
  The weekend is where the larger block goes.
  It is also where paybacks happen: the sleep banker exists precisely so that a night of extra load can be repaid within seven days - not remembered, not resented, repaid.
[The comparison that ends the conversation]
  There is one comparison worth making out loud, once, in daylight.
  The working parent's day has a start time and an end time.
[What to do on the worst weeks]
  There will be weeks when work is unusually hard - a deadline, a trip, a difficult project.
  In those weeks you do not abandon the system; you shrink it.
[What to write down]
  Write the work-night blocks and the weekend block in the same place, with names and times.
  Then the question 'whose turn' has an answer before the week starts, and nobody has to argue for their own rest at midnight.
