ON-SCREEN TEXT (deterministic; short lines only)

[This is your night]
  It is 3:14 in the morning.
  The baby is awake again, and before you even stand up one question is already running: is it my turn, or is he getting up?
[Nobody's fault, nobody's job]
  Here is the hard-to-hear part that matters: this is usually not a story about a bad partner.
  It is a story about a missing system.
[Why 'just ask for help' breaks down]
  Most couples try the same three things.
  They ask - 'can you help more?' - which produces a one-off gesture, one Saturday morning, and then the pattern resets, because a favour is not a plan.
[The breastfeeding objection, answered honestly]
  If you are breastfeeding, there is an honest objection: 'sleep through the night' is not simply available to you, and any system that pretends otherwise is lying.
  But night care is not only feeding.
[The one idea: an owner and a roster]
  The night does not need more goodwill.
  It needs an owner and a roster.
[Choose the model that fits your reality]
  There is no single correct roster - only the one that matches your actual situation.
  If a partner is present and willing, Template A is a breastfeeding-compatible split with named blocks.
[The hand-off]
  The protected block only exists if it is physically possible, so the system schedules the milk hand-off at fixed times.
  That also answers the most common and most honest objection: 'I don't hear the baby.' Deep sleepers are not a moral failing, so the system stops depending on hearing.
[The Fridge Shift Chart]
  The plan has to live where you can both see it without opening an app.
  Ours goes on the fridge: two clock times, one name per block, written by hand.
[The sleep banker]
  Resentment grows in the dark because exhaustion is invisible, so the system makes it visible and tradeable.
  One credit is covering a three-to-five-hour night block so the other person can sleep.
[The baby overrides the roster]
  Before you run any roster, both adults agree four rules.
  Infant safe sleep is paramount: the baby sleeps on their back, on a firm, flat, separate surface, free of blankets, pillows, bumpers and soft toys, in line with WHO and paediatric guidance.
[When the plan collapses]
  It will collapse some nights.
  That is not a failure of the plan; it is a night.
[When exhaustion is more than tiredness]
  This matters more than the roster.
  Severe, sustained exhaustion can mask or worsen postpartum mental-health conditions, and no schedule fixes that.
[Where to start tonight]
  You do not start with the whole system.
  You start with one named shift and one written time, tonight.
