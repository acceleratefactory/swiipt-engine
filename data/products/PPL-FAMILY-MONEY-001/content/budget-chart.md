# The One-Number Budget Chart
*The single sheet that both partners read from. Fill it once, post it where you both pass it, and review it on the date at the bottom.*

## The four lines that matter
Everything else in this system points back to these lines. Do not add more until these are filled.

| Line | Your figure | Notes |
|---|---|---|
| Normal-month baby figure | | The quiz Step 3 total |
| Lean-month figure | | What still gets covered when income dips |
| Peak-month figure | | When several yearly costs land together |
| The baby fund | | The amount you hold back each month for the yearly items |

**Reading the lines.** The four lines are not comparable to each other; each answers a different question.
- **Normal-month figure** is not a ceiling or a target. It is the honest cost of a usual month.
- **Lean and peak** exist because one fixed number fails in a household with irregular income. Showing both ends is the point.
- **The baby fund** is the monthly amount that pre-pays the once-in-a-while costs, so they stop arriving as emergencies.

**The shared rule.** Write it under the table, in the words you both agree:

> We spend against the plan, not against the fear. When something is unclear, it goes on the Buy / Wait / Never List before it is bought.

Both partners read the same chart. If the chart lives only in one phone, it is not shared yet.

> ## If the numbers change
> Income changes, prices move, and the baby changes what it needs. When a line becomes wrong, edit that line and note the date. The method does not change. Only the number does.
